## 🔄 Fluxo de Movimentação (Ciclo de Vida)

Para manter o projeto organizado, os documentos devem seguir este fluxo:

1. **Backlog (`.aidev/plans/backlog/`):**
   - Ideias brutas, rascunhos de arquitetura e propostas estratégicas.
   - Status: *Draft* ou *Validada*.

2. **Feature (`.aidev/plans/features/`):**
   - Quando uma ideia do backlog é selecionada para entrar no ciclo de desenvolvimento.
   - O documento é movido para cá e detalhado com requisitos técnicos específicos.

3. **Current Sprint (`.aidev/plans/current/`):**
   - Funcionalidades que estão sendo codificadas e testadas AGORA.
   - Link direto com o `ROADMAP.md`.

4. **Archive (`.aidev/plans/archive/`):**
   - Documentos de features concluídas e validadas em produção.

---

## 🛠️ Como Priorizar uma Ideia

1. **Mover** o arquivo de `backlog/` para `features/`.
2. **Atribuir** um número de identificação (ex: `007-user-unification.md`).
3. **Adicionar** ao `ROADMAP.md` na sprint correspondente.
4. **Executar** via comando `aidev new-feature`.
